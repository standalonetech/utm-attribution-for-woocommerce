## Classifier

`utm_attribution_get_settings()` (helpers) merges the saved option over defaults. Compiled regexes cached in statics.

- `classify_user_agent( $ua )` → `'monitor' | 'bot' | ''`. `''` UA → `'bot'`; `null` (anonymised by `purge_pii`) → `''` (keep). Setting `exclude_bots` off → `''`.
- `is_noise_path( $path )` → bool; no-op when `exclude_non_page` off.
- `is_excluded_user( $user_id )` → bool; default `user_can( $id, 'manage_woocommerce' )`; filter `utm_attribution_exclude_user`.
- `is_internal_host( $host )` → bool.
- `REPEAT_WINDOW = 30 * MINUTE_IN_SECONDS` (also replaces the literal in `is_recent_same_visit()`).

**Monitor patterns** (checked first): `jetmon uptime pingdom statuscake site24x7`.

**Bot patterns** (`#…#i`, filter `utm_attribution_bot_ua_patterns`; admin substrings `preg_quote`d and appended before the filter):
- 1.3.0 verbatim: `bot crawl spider slurp preview headless lighthouse curl wget python- go-http facebookexternalhit`
- `mediapartners-google googleother google- nexus 5x build/mmb29p scrapy okhttp axios node-fetch undici ^node$ ^java/ apache-httpclient python/ aiohttp httpx guzzlehttp libwww ^whatsapp/ ^wordpress/ meta-external`
- `geedoshop terracotta ^mozilla/5\.0$ cms-checker privacy preserving prefetch proxy`

False positives: `^whatsapp/` / `^wordpress/` / `^node$` / `^mozilla/5\.0$` are anchored (WhatsApp in-app browser sends the WebView/Safari UA; real browsers always append platform tokens). Real Nexus 5X on the 2015 MMB29P build is negligible.

**Non-page paths** (filter `utm_attribution_noise_path_patterns`, path only): `/\.well-known/`, `sitemap[^/]*\.xml(?:\.gz)?$`, `\.(?:txt|xml|json|ico|webmanifest)$`, `/feed/?$`; live also `is_favicon()`. Admin paths are `preg_quote`d and anchored to the start of the path (after any subdirectory install prefix).

Broken pattern from a filter → `preg_match` false → treated as "not noise" (fail open), `_doing_it_wrong` under `WP_DEBUG`.

**Internal host:** referrer host (www. stripped) equals the site host (exact, as in 1.3.0), or equals/is a subdomain of an `internal_domains` entry (filter `utm_attribution_internal_domains`, default = the Settings list), via existing `host_matches()`. Subdomains of the site host are NOT assumed internal (a blog/newsletter subdomain can be a real traffic source; review finding, 1.3.1). Parent/sibling domains are never inferred.

## Live capture order (`wp`, priority 1)

1. Existing `is_admin()` / AJAX / cron skip.
2. `is_noise_request()`: 1.3.0 request checks (always) → `is_favicon()` + `is_noise_path()` (if `exclude_non_page`) → `classify_user_agent() !== ''` (if `exclude_bots`) → `Sec-Purpose`/`Purpose` contains `prefetch` (if `ignore_prefetch`) → `is_excluded_user()` (if `exclude_staff`) → `utm_attribution_skip_capture` keeps the final say (unchanged signature).
3. Existing cookie / same-tag-reload logic unchanged (tagged hits always create a visit unless a same-cookie reload).
4. Internal referral → `is_internal_host()`.
5. **Repeat merge** — only when no UTM, no valid cookie, `merge_repeat_visits` on, and ip hash not null: `SELECT id … WHERE ip_hash = %s AND visited_at >= now-30min AND user_agent = %s AND utm_source = %s AND utm_medium <=> %s LIMIT 1` (source and medium of *this* request, so a visitor arriving from a different source behind a shared IP is still recorded; review finding, 1.3.1). Found → return, **no insert and no cookie** (a match may be a different person behind carrier NAT; handing them another visit id would misattribute their order). Window anchors on the last stored row.
6. `store_visit()` unchanged.

**Prefetch default OFF.** Chrome reuses a prefetched response without re-requesting when the user clicks, keeping its cookies only then. Skipping prefetch loses clicked organic visits and their conversions; recording them only inflates visits for unclicked results. The 115 "Prefetch Proxy" rows are `/.well-known/traffic-advice` fetches, already caught by UA/path rules. Toggle stays with help text.

## Settings page

Submenu `utm-attribution-settings` after Conversions, same capability. `register_setting( 'utm_attribution_settings', 'utm_attribution_settings', sanitize )`, submits to `options.php`; `option_page_capability_utm_attribution_settings` returns the plugin capability. 1.3.2 adds a Tools tab (`&tab=tools`).

| Section | Key | Default | Sanitize |
|---|---|---|---|
| Traffic filtering | `exclude_bots` | 1 | bool |
| | `extra_bot_patterns` (textarea, one per line, plain substring) | [] | split `\R`, sanitize_text_field, lowercase, 4–100 chars, unique, max 50; refused if it matches the saving admin's own UA; settings error if dropped |
| | `exclude_non_page` | 1 | bool |
| | `extra_noise_paths` | [] | must start `/`, 4–200 chars, query stripped, max 50; matches the **start** of the path (after a subdirectory install prefix); refused if it is a prefix of the home path |
| | `ignore_prefetch` | **0** | bool |
| | `merge_repeat_visits` | 1 | bool; warning if `ip_hashing` 0 |
| | `exclude_staff` | 1 | bool |
| | `internal_domains` | [] | host via `wp_parse_url` if scheme, lowercase, strip `www.`/`*.`, valid hostname ≤253, max 20 |
| Attribution | `attribution_window_days` | 30 | absint 1–365 |
| | `user_stitching` | 0 | bool |
| Privacy | `ip_hashing` | 1 | bool; help "Required for merging repeat visits" |
| | `pii_retention_days` | 365 | absint 0–3650 (0 = keep) |

Unknown keys dropped. Escape with `checked()`, `esc_attr()`, `esc_textarea()`. Show a note when a code filter overrides a saved value.

## Edge cases

| Scenario | Handling |
|---|---|
| Carrier NAT, same UA within 30 min | Second person not recorded, never given someone else's visit; setting can be turned off |
| IP hashing off | Merge inactive; settings warning |
| Anonymised rows (NULL UA) | Classified keep |
| Admin enters `/`, short text, text matching own browser, or a prefix of the home path | Rejected (min 4, must start with `/` for paths) |
| Broken regex from a filter | Fail open + debug notice |
| Clicked prefetched result | Recorded (prefetch skip off by default) |
| Existing sites upgrading | Index added via `maybe_upgrade`; nothing deleted |
| Uninstall | `delete_option( 'utm_attribution_settings' )` |
